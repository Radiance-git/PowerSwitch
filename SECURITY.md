# Security Policy

## Supported Versions

Security updates are currently provided for the latest version of PowerSwitch.

| Version | Supported |
| ------- | --------- |
| Latest  | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in PowerSwitch, please do not report it through a public GitHub issue.

Instead, report it privately through GitHub's private vulnerability reporting feature, if enabled for this repository.

Please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected version
- The expected and actual behavior
- Any relevant logs or proof-of-concept information

Please avoid including sensitive personal information in the report.

## Response

Security reports will be reviewed as soon as reasonably possible.

If the vulnerability is confirmed, appropriate steps will be taken to address it and publish a fix when necessary.

## Scope

This policy covers the PowerSwitch project and its source code, installation scripts, systemd service, and related project configuration.
